# Repositório de Estudos e Projetos de Desenvolvimento

Este repositório contém uma coleção de projetos e estudos focados em diversas tecnologias web, organizados por linguagem e framework para facilitar a navegação e o aprendizado. Cada pasta representa um projeto ou um conjunto de exemplos sobre um tópico específico.

## Estrutura do Repositório

O repositório está organizado nas seguintes categorias principais:

*   `html-css/`: Projetos focados principalmente em HTML e CSS, incluindo layouts, design responsivo e animações puras de CSS.
*   `javascript/`: Projetos que demonstram o uso de JavaScript para interatividade, lógica de aplicações, consumo de APIs e manipulação do DOM.

## Projetos

### HTML & CSS

*   **[Animations CSS](./html-css/animations-css/)**: Uma coleção de exemplos e experimentos com animações e transições utilizando apenas CSS.
*   **[Responsive Landing Page](./html-css/responsive-landing-page/)**: Demonstração de uma landing page responsiva, projetada para se adaptar a diferentes tamanhos de tela.

### JavaScript

*   **[Calculator](./javascript/calculator/)**: Uma calculadora funcional implementada com HTML, CSS e JavaScript.
*   **[CPF Validator](./javascript/cpf-validator/)**: Um validador de números de CPF (Cadastro de Pessoas Físicas) utilizando lógica JavaScript.
*   **[Hangman Game](./javascript/hangman-game/)**: O clássico jogo da forca, implementado com HTML, CSS e JavaScript.
*   **[Interactive Animations](./javascript/interactive-animations/)**: Projetos que exploram animações mais complexas e interativas, controladas via JavaScript.
*   **[Pokemon API](./javascript/pokemon-api/)**: Uma aplicação que consome a PokeAPI para exibir informações de Pokémon.
*   **[Registration Form](./javascript/registration-form/)**: Um formulário de cadastro interativo com validação de campos em tempo real usando JavaScript.

## Como Executar os Projetos

Para a maioria dos projetos, basta abrir o arquivo `index.html` no seu navegador. Alguns projetos podem exigir um servidor local (como Live Server no VS Code) para funcionar corretamente devido a restrições de segurança do navegador (CORS ou carregamento de módulos JS).
