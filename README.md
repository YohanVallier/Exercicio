# Coleção de Estudos e Projetos de Desenvolvimento

Este repositório serve como um compêndio de estudos, exercícios e projetos desenvolvidos em diversas linguagens e plataformas, incluindo Python, JavaScript, HTML e CSS. Abrange desde exercícios fundamentais de cursos como "Curso em Vídeo", Alura e Udemy, até mini-projetos mais elaborados.

## Estrutura do Repositório

Uma visão geral dos principais diretórios e seus conteúdos:

*   `Casa do Código/`: Contém dados e scripts relacionados a conteúdos da plataforma Casa do Código.
    *   `Casa do Código/dados/`: Armazenamento de arquivos de dados.
*   `Curso em Vídeo/`: Inclui exercícios propostos e arquivos temporários de execução de scripts.
*   `Exercícios Curso em Vídeo/`: Uma coleção de exercícios de programação.
*   `data/`: Diretório dedicado ao armazenamento de diversos conjuntos de dados.
    *   `data/casa-do-codigo/`: Dados e metadados específicos da Casa do Código.
    *   `data/hashtag-trainings/`: Conjuntos de dados utilizados em treinamentos da Hashtag.
*   `docs/`: Documentação geral, incluindo licenças.
*   `javascript-exercises/`: Coleção de exercícios em JavaScript de diferentes fontes.
    *   `javascript-exercises/curso-em-video/`: Exercícios do Curso em Vídeo.
    *   `javascript-exercises/udemy-web-modern/`: Exercícios de um curso da Udemy, organizados por tópicos como `array` e `function`.
*   `python/`: Contém projetos e notebooks em Python.
    *   `python/alura-data-science/`: Notebooks Jupyter de cursos de Data Science da Alura.
    *   `python/casa-do-codigo/`: Scripts e notebooks relacionados à Casa do Código.
    *   `python/hashtag-trainings/`: Notebooks e scripts de treinamentos da Hashtag.
*   `python-exercises/`: Exercícios de programação em Python.
    *   `python-exercises/curso-em-video/`: Exercícios do Curso em Vídeo.
*   `web-exercises/`: Exercícios de desenvolvimento web.
    *   `web-exercises/curso-em-video/`: Exercícios web do Curso em Vídeo.
*   `web-projects/`: Projetos completos de desenvolvimento web.
    *   `web-projects/alura-plus/`: Projeto web "Alura Plus".
    *   `web-projects/alura-portfolio/`: Projeto de portfólio web desenvolvido com Alura.
    *   `web-projects/curso-em-video/`: Diversos projetos web do Curso em Vídeo, como `android-project`, `cordel-project`, `login-project`, `video-gallery` e uma série de exercícios (`exercises/ex001` a `ex005`).

## Linguagens e Tecnologias

### Python

A seção Python deste repositório inclui:

*   **Exercícios do Curso em Vídeo**: Uma série abrangente de `exercicioXXX.py` (`python-exercises/curso-em-video/`) cobrindo fundamentos de programação, lógica e estruturas de dados.
*   **Projetos Alura Data Science**: Notebooks Jupyter (`.ipynb`) focados em análise e manipulação de dados, como `hora_da_pratica.ipynb` e `sorteio_de_pessoas.ipynb` (`python/alura-data-science/`).
*   **Scripts Casa do Código**: Arquivos Python para download, leitura e estruturação de dados (`python/casa-do-codigo/`).
*   **Treinamentos Hashtag**: Notebooks Jupyter (`.ipynb`) e scripts para automação, análise de dados e resolução de problemas práticos (`python/hashtag-trainings/`).
*   Arquivos isolados de exercícios como `Exercício029.py` em `Exercícios Curso em Vídeo/`.

### JavaScript

A seção de JavaScript abrange:

*   **Exercícios do Curso em Vídeo**: Uma coleção de arquivos `.js` (`javascript-exercises/curso-em-video/`) para prática de conceitos variados, como `ex009.js` a `ex013.js`.
*   **Exercícios Udemy Web Modern**: Scripts focados em tópicos como manipulação de `array` (`javascript-exercises/udemy-web-modern/array/`) e `function` (`javascript-exercises/udemy-web-modern/function/`), incluindo listas de exercícios detalhadas.
*   **Scripts de Interatividade Web**: Arquivos `script.js` integrados a projetos web para adicionar dinamismo e interatividade (`web-projects/curso-em-video/exercises/`).
*   Arquivos temporários de execução (`Curso em Vídeo/node_XXX.tmp.js`).

### HTML/CSS

O repositório contém uma vasta gama de projetos e exercícios de desenvolvimento web, utilizando HTML para estruturar o conteúdo e CSS para estilização e design:

*   **Exercícios Fundamentais**: Arquivos `.html` em `web-exercises/curso-em-video/` que demonstram conceitos básicos e intermediários de HTML.
*   **Projetos Alura**:
    *   **Alura Plus**: Um projeto web completo com `index.html` e estilização em `style.css` (`web-projects/alura-plus/`). Inclui diversos recursos visuais (`.png`).
    *   **Alura Portfolio**: Um projeto de portfólio pessoal com `index.html` e `about.html`, acompanhados de estilos em `style.css` e várias imagens (`.png`, `.jpg`, `.svg`) e ícones de redes sociais (`web-projects/alura-portfolio/`).
*   **Projetos Curso em Vídeo**:
    *   **Android Project**: Simulação de um site sobre a história do Android, com `index.html`, `style.css` (`web-projects/curso-em-video/android-project/`) e recursos como imagens (`.png`, `.jpg`), ícones (`.ico`) e fontes personalizadas (`.otf`).
    *   **Cordel Project**: Uma página web no estilo cordel, utilizando `index.html`, `style.css` e imagens de fundo (`.jpg`) para efeitos visuais (`web-projects/curso-em-video/cordel-project/`).
    *   **Exercícios Interativos (Ex001 a Ex005)**: Cada exercício possui seu próprio `index.html`, `style.css` e `script.js` (`web-projects/curso-em-video/exercises/`), explorando conceitos como relógio dinâmico, verificador de idade e tabuada.
    *   **Login Project**: Uma página de login responsiva com `index.html` e `style.css`, utilizando imagens (`.jpg`) e ícones SVG (`.svg`) (`web-projects/curso-em-video/login-project/`).
    *   **Video Gallery**: Uma galeria de vídeos com múltiplas páginas HTML para cada vídeo e um `index.html` principal, estilizada com `style.css` e imagens de miniaturas (`.png`) (`web-projects/curso-em-video/video-gallery/`).

### Outros Arquivos

*   `.gitignore`: Define padrões de arquivos e diretórios a serem ignorados pelo Git.
*   `.md`: Arquivos Markdown, como `data/casa-do-codigo/readme.md` e `docs/license`, contendo documentação e informações importantes.
*   `.csv`, `.xlsx`: Arquivos de dados brutos e planilhas eletrônicas, usados em diversos projetos para análise.
*   `.txt`, `.log`: Arquivos de texto genéricos e logs de execução, como `automacao.log` e `coletor.txt`.
*   `.DS_Store`: Arquivos de sistema gerados pelo macOS.
